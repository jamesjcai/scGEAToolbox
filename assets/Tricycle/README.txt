neuroRef.tsv -- tricycle's pre-learned cell-cycle projection matrix

Source: the "neuroRef" data set of the Bioconductor package tricycle,
version 1.20.0, exported unchanged (full double precision) with R.
500 genes; pc1_rot and pc2_rot are the two rotation columns learned from
mouse neurosphere data. human_symbol is tricycle's own human mapping
(the "SYMBOL" column).

tricycle is licensed under GPL-3. This file is a copy of its data and is
distributed under the same license, GPL-3, not under the license of the
rest of scGEAToolbox.

Reference:
Zheng SC, Stein-O'Brien G, Augustin JJ, et al. Universal prediction of cell
cycle position using transfer learning. Genome Biology 23, 41 (2022).
https://doi.org/10.1186/s13059-021-02581-y

Used by run.ml_tricycle.
